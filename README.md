## EndNote 的几个真实限制

买断不等于免费升级，这是最容易被误解的一点。你付的 275 美元买的是一次买断加当前这个大版本，下一个大版本出来，从 21 升到 2025 要再付 125 美元。官方明码标价，不算隐藏收费，但预算里得算进去。

云存储的“3 年不限量”要留意。圣地亚哥分校的指南写的是桌面版附 3 年不限量的 PDF 存储。3 年之后怎么算，这句话没说，长期项目、资料量大的用户要自己去官方确认续期政策。

学校不一定有授权，别假设。前面提过，加州大学圣地亚哥分校明确没有全校授权，你查了才知道。

虚拟商品不退款。荔枝数码的购买须知写得很直白，除法律强制性规定或店铺规则另有约定外，商品一经交付不退款。买之前先用试用版把你自己那篇论文的模板跑一遍，确认输出格式对得上再付款。

店铺提供的支持范围有限。购买须知里写明，店铺只提供软件安装、注册激活这类基础支持。文献格式调不对、Word 插件冲突这类问题，得找 Clarivate 的官方支持。
